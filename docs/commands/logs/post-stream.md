## linodectl logs post-stream

Create a stream

### Synopsis

Consider these points before creating a stream: - You first need to [create the destination](https://techdocs.akamai.com/linode-api/reference/post-destination) where you want to store log data. - By default, you can only set up a single stream for each audit log type. Talk to your account team if you need additional streams. - This operation can only be accessed by account [users](https://techdocs.akamai.com/linode-api/reference/get-users) with _unrestricted_ access.
