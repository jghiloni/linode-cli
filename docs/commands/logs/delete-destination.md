## linodectl logs delete-destination

Delete a destination

### Synopsis

Delete a specific logs destination. Include the appropriate `destinationId` as a path parameter. This operation can only be accessed by account [users](https://techdocs.akamai.com/linode-api/reference/get-users) with _unrestricted_ access. Talk to your local account administrator about access management. You can't delete a destination that's part of an active logs stream: 1. With your target `destinationId` stored, run the [List streams](https://techdocs.akamai.com/linode-api/reference/get-stream) operation and store the `id` for all streams that are using the destination. 2. Run the [Update a stream](https://techdocs.akamai.com/linode-api/reference/put-stream) operation for each stored stream `id`, and remove the target destination. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `monitor:read_write` **CLI** ```shell linode-cli destination-delete 456 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
