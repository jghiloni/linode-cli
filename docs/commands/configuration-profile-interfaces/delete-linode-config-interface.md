## linodectl configuration-profile-interfaces delete-linode-config-interface

Delete a configuration profile interface

### Synopsis

Deletes a configuration profile interface from a specific configuration profile, on a specific Linode. A successful request triggers a `linode_config_update` [event](https://techdocs.akamai.com/linode-api/reference/get-events). Consider these points before deleting a configuration profile interface: - You can't delete an active configuration profile interface. First, you need to shut down the associated Linode or restart it using another configuration profile. - You can't delete a configuration profile interface from a Linode that has a `cannot_delete_with_subresources` [resource lock](https://techdocs.akamai.com/linode-api/reference/post-resource-lock) set for it. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Permissions: `delete_linode_config_profile_interface` - **OAuth scopes**. Your user needs these scopes assigned.
