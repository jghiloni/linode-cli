## linodectl identity-management put-iam-users-role-permissions

Update a user's access level

### Synopsis

Updates a user's access level on the account. The request includes account access and entity access roles. - **Account access roles**. These roles give access to account level operations, entities in the account both existing and to be created in the future, and creation of new entities. - **Entity access roles**. These roles provide access to specific entities that are already available on the account. To learn more, see the [Identity and Access in Cloud Manager terminology](https://techdocs.akamai.com/cloud-computing/docs/identity-and-access-cm#terminology). This operation replaces any existing role assignment. To completely block user's access to the account, pass an empty list, `[]`.
