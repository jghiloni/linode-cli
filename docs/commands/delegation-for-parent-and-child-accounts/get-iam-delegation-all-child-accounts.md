## linodectl delegation-for-parent-and-child-accounts get-iam-delegation-all-child-accounts

List child accounts

### Synopsis

Returns the list of available child accounts under your parent account. With the `users` query parameter set to `true`, it also returns the account delegation for each child account. An *account delegation* is a group of parent account users, either admin or non-admin, delegated to manage a specific child account. The child account's admins manage the role assignment of delegate users on the child account.
