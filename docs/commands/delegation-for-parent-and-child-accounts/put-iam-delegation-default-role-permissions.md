## linodectl delegation-for-parent-and-child-accounts put-iam-delegation-default-role-permissions

Update the default role assignment for delegate users

### Synopsis

Updates the default role assignment for new delegate users on your child account. A *delegate user* is a user from the parent account delegated by a parent account's admin on the parent account to have access to your, child, account. Note that the change applies only to new delegate users coming to your account. To edit current delegate users' access, you need to run the [Update a user's access level](https://techdocs.akamai.com/linode-api/reference/put-iam-users-role-permissions) operation.
