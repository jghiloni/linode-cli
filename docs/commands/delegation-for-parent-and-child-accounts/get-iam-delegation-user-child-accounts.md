Get user's account delegations

### Synopsis

Returns the list of child accounts a specific user is part of the account delegation for. An *account delegation* is a group of parent account users, either admin or non-admin, delegated to manage a specific child account. The child account's admins manage the role assignment of delegate users on the child account.
