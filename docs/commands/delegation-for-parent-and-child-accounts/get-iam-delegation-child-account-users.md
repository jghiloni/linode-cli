## linodectl delegation-for-parent-and-child-accounts get-iam-delegation-child-account-users

Get the account delegation for a child account

### Synopsis

Returns the list of users added to the account delegation for a specific child account. An *account delegation* is a group of parent account users, either admin or non-admin, delegated to manage a specific child account. The child account's admins manage the role assignment of delegate users on the child account.
