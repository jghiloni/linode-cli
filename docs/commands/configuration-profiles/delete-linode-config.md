## linodectl configuration-profiles delete-linode-config

Delete a configuration profile

### Synopsis

Delete a specific configuration profile from the specified Linode. You can't delete a configuration profile from a Linode that has a `cannot_delete_with_subresources` [resource lock](https://techdocs.akamai.com/linode-api/reference/post-resource-lock) set for it. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Permissions: `delete_linode_config_profile` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `linodes:read_write` **CLI** ```shell linode-cli linodes config-delete 123 23456 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
