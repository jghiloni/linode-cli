## linodectl control-plane-acl delete-lke-cluster-acl

Delete the control plane access control list

### Synopsis

Disables control plane access controls and deletes all rules. It has the same effect as calling `PUT` with an ACL JSON map value of `{"enabled": false}`. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Roles: `lkecluster_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `lke:read_write` **CLI** ```shell linode-cli lke cluster-acl-delete 12345 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
