## linodectl domains delete-domain

Delete a domain

### Synopsis

Deletes a domain from DNS Manager. The domain will be removed from our nameservers shortly after this operation completes. This also deletes all associated domain records. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Roles: `domain_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `domains:read_write` **CLI** ```shell linode-cli domains delete 1234 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
