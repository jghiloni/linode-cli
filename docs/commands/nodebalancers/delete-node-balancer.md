## linodectl nodebalancers delete-node-balancer

Delete a NodeBalancer

### Synopsis

Deletes a NodeBalancer. __This is a destructive action and cannot be undone.__ A NodeBalancer can't be deleted if it has a `cannot_delete` or a `cannot_delete_with_subresources` lock. Only account administrators can remove locks using the [Delete a resource lock](https://techdocs.akamai.com/linode-api/reference/delete-resource-lock) operation. Deleting a NodeBalancer also deletes all associated configurations and nodes. However, the backend servers represented by these nodes are not changed or removed. When you delete a NodeBalancer, you lose access to the IP addresses assigned to it. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Permissions: `delete_nodebalancer` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `nodebalancers:read_write` **CLI** ```shell linode-cli nodebalancers delete 12345 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
