## linodectl idp-configuration put-idp-config

Update an IDP configuration

### Synopsis

__Beta__ Updates the external identity provider (IDP) configuration for the account. Top-level properties can be passed individually or together. When included, you need to provide the entire IDP config object and it will overwrite existing values. This operation triggers an `update_idp_config` event. > blue-book > > This operation is in Beta and available from the `v4beta` URL. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Permissions: `update_idp_config`
