# IDP configuration

## linodectl idp-configuration

idp-configuration operations

### Synopsis

Use the Identity Management IDP Configuration endpoints to configure SAML-based Single Sign-On (SSO) for your account. You can create and manage an external identity provider (IDP) configuration, control which users are required to authenticate through SSO, and manage the public certificates used to verify SAML assertions. These endpoints are in Beta and available from the `v4beta` URL.
