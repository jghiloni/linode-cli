## linodectl linode-instances post-mutate-linode-instance

Upgrade a Linode

### Synopsis

Linodes created with now-deprecated Types are entitled to a free upgrade to the next generation. A mutating Linode will be allocated any new resources the upgraded Type provides, and will be subsequently restarted if it was currently running. If any actions are currently running or queued, those actions must be completed first before you can initiate a mutate. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**.
