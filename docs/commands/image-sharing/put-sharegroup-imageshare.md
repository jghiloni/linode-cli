## linodectl image-sharing put-sharegroup-imageshare

Update a shared image

### Synopsis

Updates the details of an image shared within a share group. Run this operation to edit the `label` and `description` of a particular shared image. - Run the [List share groups](https://techdocs.akamai.com/linode-api/reference/get-sharegroups) operation to get the `id` you should use as the `(sharegroupId)` path parameter that identifies an existing share group. To get the `imageID`, run the [List shared images by group](https://techdocs.akamai.com/linode-api/reference/get-sharegroup-images) operation. - You can update either of the fields, but when you provide a new `label`, make sure that it's not an empty string. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **OAuth scopes**. Your user needs these scopes assigned.
