## linodectl payment-methods delete-payment-method

Delete a payment method

### Synopsis

Deactivate the specified Payment Method. The default Payment Method can not be deleted. To add a new default Payment Method, run the [Add a payment method](https://techdocs.akamai.com/linode-api/reference/post-payment-method) operation.
