## linodectl manage-beta-programs post-beta-program

Enroll in a Beta program

### Synopsis

Enroll your account in an active Beta program. When running this operation, consider these points: - To view active Beta programs, run the [List beta programs](https://techdocs.akamai.com/linode-api/reference/get-beta-programs) operation. - Active Beta programs may have a limited number of enrollments. If a program has reached its maximum number of enrollments, you'll get an error even though the request is successful. - Beta programs with `"greenlight_only": true` can only be enrolled in by an accounts that participates in the [Greenlight](https://www.linode.com/green-light/) program. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions.
