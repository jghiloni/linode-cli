## linodectl lke-node-pools post-lke-cluster-pool-recycle

Recycle a node pool

### Synopsis

Recycles a node pool for the designated Kubernetes cluster. All Linodes within the node pool will be deleted and replaced with new Linodes on a rolling basis, which may take several minutes. Replacement nodes are installed with the latest available patch for the cluster's Kubernetes version. __Any local storage on deleted Linodes (such as `hostPath` and `emptyDir` volumes, or `local` PersistentVolumes) will be erased.__ **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Roles: `lkecluster_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `lke:read_write` **CLI** ```shell linode-cli lke pool-recycle 12345 456 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
