## linodectl lke-node-pools delete-lke-node-pool

Delete a node pool

### Synopsis

Delete a specific node pool from a Kubernetes cluster. __Deleting a node pool is a destructive action and can't be undone.__ Deleting a node pool deletes all Linodes within that pool. Account administrators can configure a resource lock with the [Create a resource lock](https://techdocs.akamai.com/linode-api/reference/post-resource-lock) operation to prevent a node pool from being deleted. They can also remove the lock with the [Delete a resource lock](https://techdocs.akamai.com/linode-api/reference/delete-resource-lock) operation. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Roles: `lkecluster_admin` - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `lke:read_write` **CLI** ```shell linode-cli lke pool-delete 12345 456 ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
