## linodectl personal-access-tokens delete-personal-access-token

Revoke a personal access token

### Synopsis

Revokes a personal access token. The token will be invalidated immediately, and requests using that token will fail with a 401. It is possible to revoke access to the token making the request to revoke a token, but keep in mind that doing so could lose you access to the api and require you to create a new token through some other means. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**.
