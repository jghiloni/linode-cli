## linodectl alerts post-notification-channel

Create a notification channel

### Synopsis

__Limited availability__ Create a new notification channel, to set up a communication method for a monitoring alert. This is referred to as a `user` channel and you can have a maximum of five on your account. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **OAuth scopes**. Your user needs these scopes assigned. [Learn more](https://techdocs.akamai.com/linode-api/reference/get-started#oauth). - Scopes: `monitor:read_write` **CLI** ```shell linode-cli alerts channels-create --label Email channel for Managed Database alerts \ --channel_type email \ --details.email.usernames johndoe \ --details.email.usernames janedoe ``` [Learn more](https://techdocs.akamai.com/cloud-computing/docs/getting-started-with-the-linode-cli)
