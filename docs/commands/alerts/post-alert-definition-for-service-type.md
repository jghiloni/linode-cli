## linodectl alerts post-alert-definition-for-service-type

Create an alert definition

### Synopsis

__Limited availability__ Create a new alert definition for a specific service type. Akamai refers to these as `user` alerts. You need `read_only` access to the [OAuth scope](https://techdocs.akamai.com/linode-api/reference/get-started#oauth-reference) for the selected `serviceType`. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **OAuth scopes**. Your user needs these scopes assigned.
