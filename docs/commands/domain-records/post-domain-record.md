## linodectl domain-records post-domain-record

Create a domain record

### Synopsis

Adds a new domain record to the zonefile this domain represents. Each domain can have up to 12,000 active records. **Permissions and scopes** To call this operation, you need permissions, based on the model you're using: - **Identity and access permissions**. Your user needs a role with these permissions. [Learn more](https://techdocs.akamai.com/cloud-computing/docs/identity-access-cm-available-roles). - Roles: `account_domain_creator` - **OAuth scopes**. Your user needs these scopes assigned.
